# Agent dispatch

先算再派：`node scripts/agent.mjs plan "<任务>" --save` 出派工单，按单执行。

## 派不派
- L0：不派。派出去的钱常比活本身贵。
- L1：最多 1 个只读审查者。自己写，别人看。
- L2：侦察（只读）→ 实现（单写者）→ 审查（只读）三段式。
- 上下文快满、任务能切成互不重叠的目录：派。要连续改同一处逻辑：不派，串行更快。

预设角色（investigator / builder / reviewer）见 `cavecrew`；本技能负责"派不派、派几个、怎么收口"。

## 划分
每个子代理只拿：目标、验收条件、它能读的文件范围、禁止事项、交付格式。
不给全量仓库、不给你的结论——给了它就会替你背书。

## 纪律
- **写者唯一**：任一时刻一个文件只有一个写者；两个子代理同时改同一文件即回退串行。
- 可并行：检索、只读侦察、互不依赖的测试套件；其余串行。
- 子代理的自述不算证据，只看命令输出、diff、截图 JSON。
- 审查不过回实现，**最多两轮**；两轮不过停下问用户，别烧第三轮。
