# 选题手册：从一句话到指标与图表

## 1. 先定"看什么"，再定"怎么画"

大屏的本质是**替人做判断**。每个面板都要能回答一句业务问题：

| 面板 | 回答的问题 |
| --- | --- |
| KPI 行 | 现在整体好不好？ |
| 主趋势 | 在变好还是变坏？ |
| 排行 | 哪里好、哪里差？ |
| 构成 | 钱/量从哪来？ |
| 事件流 | 刚刚发生了什么？ |
| 明细/健康度 | 有没有隐患？ |

凑不出一句业务问题的面板，删掉。

## 2. 行业 → 指标 → 图表

| 题材 | 5 个 KPI | 主趋势 | 左栏 | 右栏 |
| --- | --- | --- | --- | --- |
| 电商/零售 | GMV、订单、客单价、退款率、在线商品 | 成交额（今日/本周/本月） | 品类排行、渠道构成、履约水位 | 转化漏斗、实时订单、店铺健康度 |
| 物流/冷链 | 在途运单、准时率、异常件、平均时长、冷链温度达标率 | 单量趋势 | 线路排行、货类构成、车辆水位 | 温控告警、在途事件、网点健康度 |
| 制造/工业 | 产量、OEE、良率、停机时长、能耗 | 产线节拍 | 车间排行、产品结构、设备水位 | 工单进度、异常事件、设备健康度 |
| 能源/电力 | 发电量、负荷、消纳率、碳减排、可用率 | 负荷曲线 | 场站排行、能源结构、储能水位 | 功率预测、调度事件、设备健康度 |
| 政务/城市 | 办件量、办结率、平均时长、满意度、在办事项 | 办件趋势 | 区县排行、事项构成、窗口水位 | 热线分布、实时事件、系统健康度 |
| 金融/风控 | 交易额、笔数、成功率、风险拦截、平均响应 | 交易趋势 | 渠道排行、业务构成、额度水位 | 风险分布、告警事件、系统健康度 |
| 医疗/院区 | 门诊量、床位使用率、手术台次、平均候诊、药品周转 | 就诊趋势 | 科室排行、病种构成、床位水位 | 急诊动态、院感事件、设备健康度 |
| 农业 | 种植面积、产量、灌溉水量、土壤墒情、设备在线 | 产量趋势 | 基地排行、作物构成、水资源水位 | 气象预警、农事事件、设备健康度 |
| 港口/机场 | 吞吐量、在港船舶/航班、泊位/机位利用率、平均在港时长、告警 | 吞吐趋势 | 泊位效率、货种构成、设备状态 | 船期/航班动态、作业进度、安全事件 |
| 园区/楼宇 | 入驻企业、在园人数、空间使用率、能耗、事件数 | 人流趋势 | 楼宇排行、产业构成、车位水位 | 能耗构成、通行事件、安防健康度 |

数字要给"像真的"的量级：GDP 类用亿/万亿，单量用万，比率保留 1–2 位小数，同比 ±3%–15%，不要出现 99.99% 之外的假精确。

## 3. 图表选型

| 想表达 | 用 |
| --- | --- |
| 连续变化 | 折线 + 面积渐变（默认主图） |
| 分类对比 | 横向条形 / 排行列表 |
| 占比 | 环形（≤5 项）+ 图例；超过 5 项改条形 |
| 分布 | 直方图 / 热力点阵（`H.matrix`） |
| 进度/水位 | 进度条、环形进度 |
| 时间事件 | 时间线 |
| 空间关系 | 3D 场景 / 地图（observatory 预设） |

**一个屏幕最多 1 个环形图、1 个折线主图**，其余用列表和条形，视觉才不吵。

## 4. 文案规范

- 标题 ≤ 10 字，副标英文全大写 + 字距拉开
- 面板标题 4–8 字，名词短语（"区域业务排行" 而非 "各个区域的业务量排行情况"）
- 结论句一句话，≤ 30 字，带具体数字："峰值出现在 18:00，实时请求 88 万次"
- 事件文案："主体 + 动作 + 结果"（"华东节点扩容完成"），备注补数字
- 不要感叹号、不要"非常""显著"这类空词

## 5. 交付前自检（逐条打勾）

1. `verify.mjs` 返回 `ok: true`，`errors` 为空
2. `audit.overflow` 为空
3. 截图里：标题不换行、数字不折行、面板不空、无 `NaN/undefined`
4. 切一遍周期按钮，图表与结论句同步变化
5. 点一个 KPI，弹窗能开能关
6. observatory：`audit.renderer === "webgl"`，模型居中不穿地，pin 不重叠
7. 单文件版（standalone）打开一次，确认离线可看
8. 页脚有"演示数据"说明
