# Goal tracker

目标一旦超过一轮能做完，先落账本再动手：`node scripts/checkpoint.mjs start "<任务>" --steps "a|b|c"`。
续跑时先 `resume`，别凭记忆重来。

## 步骤
- 每步开工前把它置为 in_progress，收工写 `done "<步>" --note "证据：命令/输出/路径"`。
- note 只写可验证的东西：命令、退出码、文件路径、失败原因。不写"已完成"。
- 会话中断/超时先把当前步的 note 写上，下一次从这里续。

## 停手规则
- 同一问题连续两轮无进展 → 停，报告"卡在哪、已排除什么、需要什么"。
- 需要用户决策（花钱、对外发送、删数据、改方向）→ 停下问，不自作主张。
- 计划不再适用 → 提修改方案让用户拍板，不静默重写计划。

## 收口
目标完成或放弃都要显式关掉（done/cancelled），留下一条复盘：哪步最贵、下次怎么省。
