# 提示词模板（可直接复制）

## 1. 需求四段

```text
目标：<用户可见结果>
边界：只改 <目录/文件>；不动 <接口/库表/其他频道>
验收：<可勾选条件>；验证命令 `node ...`
反例：不要 <明确不要的行为/风格>
```

## 2. Bug 报告

```text
报错原文：<逐字粘贴>
复现：1) … 2) … 3) …
预期 vs 实际：<应当发生> / <实际发生>
相关片段：<文件:行 或 代码块>
已试过：<方法 + 结果>
```

## 3. 方案评审

```text
方案：<一句话>
约束：<性能/兼容/时间/依赖>
请列出：2 个风险、1 个反例、回退方式，再决定是否执行。
```

## 4. 深推请求

```text
目标：<要解决的判断>
已知事实：<来源>
未知：<还缺什么>
请先写问题分解与 ≥3 个可证伪假设，再给验证顺序；未验证的结论标「推测」。
```

## 5. 复盘

```text
任务：<做了什么>
结果：成功 / 失败 / 部分
证据：<命令输出、路径、截图编号>
偏差：<与计划的差异>
沉淀：这次要写进 rules / skill / memory 的条目
```

## 6. 技能沉淀

```text
流程名：<名称>
触发：<什么时候用>
步骤：1) … 2) …
最小示例：<一条能跑通的命令或输入输出样例>
禁用：<什么时候不该用>
```
