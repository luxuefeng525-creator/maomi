# effects-menu.md — 视频动效清单(点菜单 / Effects Menu)

> 一份**给人看的"点菜清单"**。和 AI 聊视频时,直接照着点名你要哪些效果——不用懂代码。每条给「**名字**(中/EN) · **长什么样** · **怎么跟 AI 说**」。技术实现见每组末尾指向的 reference。
>
> 一条片子的结构 = **一个引擎(A)** + **入场编排(B)** + **转场(C)** + **点缀(D)** +(可选 **3D E**)+ **声音(F)**。从每层各点几样,拼成你的片子。

## A. 效果引擎 —— 承重,选**一个**做满

| 效果 | 长什么样 | 跟 AI 这么说 |
|---|---|---|
| **海报立方体翻滚** Poster-cube tumble | 贴满图片/海报的 3D 立方体入场→翻滚→展开,配编辑风标尺网格 + 巨型大字 | "用海报立方体那种,作品集感觉" |
| **胶囊翻主题** Capsule theme-flip | 一枚糖果胶囊从中心撑大,像遮罩一样扫过全屏,把画面从亮色翻成暗色 | "中间弹个胶囊把画面翻成暗色" |
| **建筑数据脉冲** Data-pulse | 摄影卡片 + 材质占比条 + 大数字滚动 + 环形图 + 图片擦除转场 | "数据报表那种,数字会滚动" |
| **粒子相册** Particle-burst album | 照片绕成 3D 环形轮播、景深虚化,再吸拢成一摞、spring 炸开成悬浮矩阵 | "照片环形转,然后炸开铺满屏" |

## B. 文字 / 元素入场(reveal)

| 效果 | 长什么样 | 跟 AI 这么说 |
|---|---|---|
| **遮罩上升** masked line rise | 文字从底部升起,像从缝里冒出来(编辑风主力) | "标题从下面升上来" |
| **逐字弹入** per-char pop | 标题一个字一个字弹进来,带一点过冲 | "大标题逐字弹出" |
| **逐词 / 逐行** per-word / per-line | 短语逐词、正文逐行依次出现 | "这句话逐词出" |
| **描边写字** SVG stroke-writing | 标题像手写一样一笔一笔画出来(最高级的标题入场) | "标题像手写一样描出来" |
| **擦除揭示** clip-path wipe | 图片/卡片从一边被"擦"出来,不是淡入 | "图片从左往右擦出来" |
| **模糊聚焦** blur-in | 从虚到实,像镜头对焦 | "hero 从模糊聚焦进来" |
| **缩放弹入** scale-pop | 数字 / 徽章 / logo 弹一下落定(spring 过冲) | "数字弹一下出来" |
| **错峰入场** stagger | 一组卡片/元素依次进场,不一起冒 | "卡片一个接一个进场" |

## C. 转场 / 出场

| 效果 | 长什么样 | 跟 AI 这么说 |
|---|---|---|
| **遮罩扫过** mask sweep | 一个形状(胶囊/圆/条)撑大扫过,翻到下一屏/下一主题 | "用遮罩扫过翻页" |
| **擦除转场** wipe | 一屏被擦成另一屏(横扫 / 中心开) | "用擦除转场" |
| **吸拢** gather | 散开的元素吸成一摞 / 一条,带速度模糊 | "照片吸拢成一摞" |
| **爆开** burst | spring 过冲,炸开成悬浮矩阵 + 翻面 + 冲击波 | "然后 spring 炸开" |
| **吸成胶片条** collapse to strip | 收尾时元素收拢成一条胶片,标题落定 | "结尾收成胶片条" |
| **有编排的退场** enter×(1−exit) | 该走的元素有方向地离场,不是硬切消失 | "元素要有退场,别硬切" |

→ 深度实现:`reveals.md` §6 / `effect-catalog.md`。

## F. 声音(配乐 + 音效)—— 手艺的一半

## 怎么用这份清单跟 AI 聊

直接**点菜**,一句话点满四层就行:

> "横屏电影感,用【粒子相册】引擎,标题【描边写字】,转场【whoosh】+【擦除】,配乐【驱动电子】,结尾【大字 wordmark 落定 + accent 闪线】,音效卡拍点。"

AI 收到后会:定 register(横/竖屏)→ 选引擎 → 铺节拍 → 编排 reveal → 配声音 → 写合成并注册。

你也可以**只点一半**,其余让 AI 按题材补;或反过来先说题材("产品发布片头"),让 AI 从这份清单里替你选,再由你调整。要改某一样,用命令:`engine`(换引擎)· `reveals`(换入场)· `sound`(换配乐/音效)· `beats`(改节奏)。
