# 视觉规范

深色科技风，克制、留白、细边框、单色强调。目标是在 3 米外看得清层级，在 30 厘米处经得起看。

## 色板（flat 预设默认值）

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#050a15` | 底色 |
| `--bg-2` | `#08101f` | 渐变第二色 |
| `--panel` | `rgba(16,27,48,.72)` | 面板 |
| `--line` | `rgba(120,170,255,.13)` | 描边 |
| `--accent` | `#3ad7ff` | 主强调（青） |
| `--accent-2` | `#7b6bff` | 次强调（紫） |
| `--accent-3` / `--ok` | `#35e0a6` | 正向 / 正常 |
| `--warn` | `#ffb340` | 预警 |
| `--bad` | `#ff5d7a` | 异常 / 负向 |
| `--text` | `#e9f2ff` | 主文字 |
| `--muted` | `#8ea3c2` | 次文字 |
| `--dim` | `#54688a` | 弱文字 / 编号 |

换行业主色只改 `--accent`（+ `--accent-2`），其余不动。可用主题：

- 青蓝（默认，通用/科技）
- 紫 `#b7a9ef`（园区、文旅、校园）
- 绿 `#bdd69a`（农业、能源、环保）
- 橙 `#eab36d`（工业、制造、矿山）
- 红 `#ff6b6b`（安防、应急、告警）

**一个屏幕最多 3 个强调色**，且必须是"主色 + 一个次色 + 状态色"。

## 字号阶梯（1920 画布，单位 px）

| 场景 | 字号 | 字重 | 字距 |
| --- | --- | --- | --- |
| 主标题 h1 | 27 | 600 | 5 |
| 英文小标 | 9.5 | 400 | 4.6 |
| 面板标题 | 13 | 600 | 1.5 |
| 面板编号 | 8.5 | 400 | 1.6 |
| KPI 数值 | 31 | 600 | .5 |
| KPI 标签 | 11.5 | 400 | 1.1 |
| 正文 / 列表 | 11–11.5 | 400 | — |
| 注释 / 时间 | 9.5–10 | 400 | — |

数字统一 `.ds-num`（DIN Alternate / tabular-nums），保证等宽跳动不抖。

## 间距与栅格

- 画布 1920×1080，外边距 30，栅格间距 16
- 面板圆角 12，内边距 11–16
- 面板高度靠 grid 等分（`grid-auto-rows:1fr`），**不要写死高度**
- 每栏面板数 3，超过 3 个必然拥挤

## 组件规范

- **面板**：1px 细边框 + 右上角 L 形高光角标 + 标题左侧图标
- **KPI**：左侧 2px 渐变竖线 + 数值 + 单位 + 涨跌 + 92×26 迷你折线
- **排行**：前 3 名实心徽章，其余描边
- **进度条**：6px 高，圆角 3，主色发光
- **事件流**：时间 / 状态点 / 文本三列，状态点带辉光
- **图表**：网格虚线 `3 5`、坐标轴弱化、数据线 2px、点半径 3、面积渐变 0.3→0.02

## 动效

- 只做"呼吸"级动效：数字滚动、led 呼吸、ticker 平移、3D 自转
- 时长 0.18–0.3s，缓动 `ease`；禁止弹跳、禁止旋转入场
- 必须响应 `prefers-reduced-motion: reduce`（停掉 ticker 与自动仿真）

## 禁忌

- 不用纯黑 `#000` 做底色（用 `#050a15`）
- 不用高饱和纯色大面积填充（> 10% 面积）
- 不用阴影做层级（用边框 + 背景明度差）
- 不堆 3D 饼图、不堆渐变文字、不加贴图底纹
- 中文不要加粗到 700（PingFang 会糊），最多 600
- 不在面板里放超过 6 行明细
