# 子代理契约

派活不是发一句「你去做 X」，而是给可验收的输入与输出。子代理看不到主会话上下文，必须自带信息。

## 派活必带

| 项 | 要求 |
| --- | --- |
| 目标 | 一句话说清做完后世界变成什么样 |
| 范围 | 允许改的目录/文件；其余只读 |
| 禁止 | 不许动的东西（库表、接口、无关频道、他人未提交文件） |
| 验收命令 | 具体命令，不接受「自己检查一下」 |
| 回报格式 | 见下，固定五段 |

## 回报格式

```
结论：做了什么（≤3 句）
改动：文件 + 意图
验证：命令 + 原始输出关键行
未完成：逐项，或「无」
风险：未覆盖场景
```

## 拒收条件

- 只说「已完成 / 应该没问题」，没有命令输出。
- 改了范围外的文件。
- 用 mock 代替真实接口或真实库。
- 把失败说成「环境问题」但没给证据。

## 并行

同一文件不并行；多任务按文件划界或使用工作树。子代理之间不共享中间结论，冲突由主控合并。
