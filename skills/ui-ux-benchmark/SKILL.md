# UI/UX 对标与验收

## 0. 立场

- 不做审美发明。「高级感」「更现代」「大气」不能作为交付依据。
- 视觉方向只能来自三处：同行截图、项目令牌、现有页面。
- 文案只过三条检查：具体化、人性化、差异化。
- 交互按闭环清单打勾，缺项写进未完成。
- 人工签收三处：对标取舍表、首屏截图、闭环清单。

## 1. 触发与定档

触发词：好看点 / 高级点 / 大气 / 简洁 / 像 XX / 参考 XX / 年轻人喜欢 / 用大白话描述页面。

- L1：单页样式或文案调整，不动路由与接口。
- L2：新页面、新路由、弹层、状态体系、跨端同步。
- 先报档位与影响面，再开工。

## 2. 对标（禁止跳步）

- 抽 3 家：同行 2 家 + 跨行 1 家。客户点名对象时直接用它，不替换。
- 每家只收四类证据：URL、截图、首屏文案原文、关键状态（hover / 加载 / 空 / 错误）。
- 设计系统文档不能当同行页面；规范只用来定判定标准。
- 产物 `docs/<任务>/BENCHMARK.md`：对标点 → 差异 → 取舍（保留 / 改造 / 放弃 + 理由）。
- 签收 1：用户确认取舍表后才进入实现。

## 3. 视觉（可判定，不谈审美）

- 只从参考取六项：栅格与间距刻度、字阶、主色与中性色、圆角阴影、组件状态、图标风格。
- 间距字号来自项目令牌或参考刻度，不临时造裸 px；新增值先写进令牌清单。
- 状态落到属性：`[data-state="open|closed"]`，不用类名猜状态。
- 焦点必须可见：禁止 `outline: none` 且无替代；焦点与 hover 可区分。
- 指针目标 ≥24×24；移动端主操作 ≥44×44。
- 动效 90–120ms、ease-out；禁弹跳曲线；必须给 reduced-motion 替代。
- 验收：截图与参考并排，逐条写「接受 / 不接受」。

## 4. 文案（三条检查 + 禁词）

- 具体化：句子含对象、数字、时间或动作。「操作成功」改为「地址已保存，预计 10 分钟送达」。
- 人性化：说人话；技术词首次出现要解释；一句一个意思（≤25 字为宜）。
- 差异化：写本业务特有的东西，不写任何行业都能套的话。
- 按钮用「动词 + 对象」：保存地址、确认下单；不用「确定 / 提交 / 了解更多」。
- 错误文案三件套：发生了什么 + 为什么 + 下一步；错误码不进用户界面。
- 空态：标题 + 下一步动作按钮；不用「暂无数据」四个字。
- 禁词：赋能、一站式、极致、重磅、立即开启、全面提升、开启新篇章、遥遥领先。
- 同页同义统一：一个概念只用一个词。

## 5. 交互闭环

按 `references/closure-checklist.md` 的 15 项逐条标注「有 / 无 / 不适用」。缺项即未完成。

硬约束：

- 错误只有一个出口：字段级错误用行内提示，整体失败用错误摘要，不叠加 toast。
- 错误摘要每条锚到出错字段，摘要文案与字段旁文案逐字一致。
- 弹层按双表验收：键盘表（Tab 循环、Esc 关闭、关闭后焦点回归）+ role/state 表。
- 反馈必须有下一步动作，不只是「失败了呢」。

## 6. 门禁与验收

- 开工前：`BENCHMARK.md` + 闭环清单就位，缺一不开工。
- 改动后：`node scripts/ui-audit.mjs --files <改动的页面文件>`
- FAIL 必修：营销词、图片缺 alt、`outline: none` 无替代、`tabindex>0`、emoji 当图标。
- WARN 进未完成清单，交付时逐条说明。
- 浏览器验收：截图 + 控制台零异常 + 键盘走查（Tab / Esc / 返回）。
- 浏览器子代理不可用时，用 `playwright-core` + 本机 Chrome 实拍，截图与 DOM 探针落 `logs/`，禁用静态代码冒充验收。
- 签收 2：首屏与关键状态截图；签收 3：闭环清单勾选结果。

## 7. 项目适配

技能本体不绑定框架。页面目录、路由注册方式、组件库、端口从 `.agent/project.md` 读取：

- `page_dirs`：页面所在目录。
- `router`：新页面需要注册到哪个文件。
- `components`：使用的组件库与设计令牌位置。
- `ports`：验收访问地址。

没有 `.agent/project.md` 时先探测仓库，把结论写进 `docs/<任务>/STACK.md`，不猜。

## 8. 反模式

紫渐变 + 玻璃拟态 + 三卡片当默认方案；只给文案不给下一步；toast 代替字段错误；空态只有「暂无数据」；动画超过 200ms 或带弹跳；焦点被移除、点击区小于 24px；拿设计系统文档冒充同行对标；没截图就宣称视觉完成。
