# 去 AI 味黑名单

判定原则：出现即改；改不了就写进未完成并说明原因。

## 视觉

| 黑名单 | 为什么 | 替换 |
| --- | --- | --- |
| 紫蓝渐变当主视觉 | 与业务无关，模板感强 | 主色取自同行或品牌色，单色为主 |
| 玻璃拟态 + 大圆角 + 柔和阴影三件套 | 组件库默认风格堆叠 | 圆角与阴影只取项目令牌一个刻度 |
| 首屏居中大标题 + 三张功能卡片 + 一排 Logo | 通用落地页模板 | 首屏先给用户要办的事（订水/查单） |
| emoji 当图标 | 跨端渲染不一致，语义不稳 | 用图标库或项目已有图标 |
| 全屏旋转 loading | 干扰、无进度信息 | 容器内骨架或进度条，90–120ms ease-out |
| 动画 300ms 以上 + 弹跳 | 拖慢操作，廉价感 | 90–120ms、ease-out，提供 reduced-motion |
| 到处发光边框 / 悬浮粒子 | 与任务无关的装饰 | 删除；装饰不得抢主操作 |

## 文案

| 黑名单 | 替换 |
| --- | --- |
| 赋能 / 一站式 / 极致 / 重磅 / 立即开启 / 开启新篇章 / 遥遥领先 | 写具体动作与结果：在线订水、30 分钟送达 |
| 操作成功 / 提交成功 | 地址已保存；订单已提交，预计 10:30 送达 |
| 暂无数据 | 还没有订单 + 「去订水」按钮 |
| 出错了，请稍后重试 | 网络断开，订单未提交；检查网络后点「重新提交」 |
| 确定 / 提交 / 了解更多 | 保存地址 / 确认下单 / 查看配送范围 |
| 为进一步优化您的体验… | 直接说做什么、得到什么 |
| 多句合并成一大段 | 一句一个意思，技术词首次出现要解释 |

## 交互

| 黑名单 | 替换 |
| --- | --- |
| 只弹 toast 不标字段 | 字段行内提示 + 顶部错误摘要（只留一个出口） |
| 点遮罩关闭但焦点丢到 body | 关闭后焦点回到触发按钮 |
| `outline: none` 且无替代 | `:focus-visible` 焦点环，深浅背景都可辨 |
| 16px 图标按钮挤成一排 | 触控区 ≥24×24；移动主操作 ≥44×44 |
| hover 与 focus 视觉相同 | 两种状态可区分 |
| 弹层打开后背景仍可滚动 | 打开锁滚动，关闭恢复 |
| 返回键失效 / 死胡同页 | 每页有唯一可达返回路径，栈深 1 也要能回 |
| 空态/错误态没有下一步 | 空态给入口，错误给重试或改法 |
