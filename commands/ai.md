# /ai · 开工

## 1 自举（拿真实状态，不猜）

```powershell
node {{PKG_ROOT}}/scripts/session-start.mjs
```

输出各行的含义：

| 行 | 含义 | 怎么用 |
| --- | --- | --- |
| `LEDGER <路径> todo/doing/blocked/done` | 当前主账本计数 | 主账本是谁、进度到哪 |
| `NEXT <ID> <标题>` | 下一件可做任务 | 直接告诉用户「下一件是它」 |
| `NEXT NONE` | 全部完成或全部阻塞 | 问用户本轮要做什么 |
| `LEDGERS 其余未完成 N 个` | **其他**账本还有欠账 | 必须一并报出，否则会漏 |
| `VERSION` | 安装版本 | 与上游不一致时提示 `/ai-doctor` |
| `MEMORY` | 记忆索引是否存在 | 缺失提示 `memory.mjs init` |

## 2 定档并当场报出来

格式固定一行：`[档位] L1 · 单端 3 文件 · 不动库表`

判据读 `.trae/skills/project-orchestrator/SKILL.md`：

| 档 | 判据（全部满足） |
| --- | --- |
| L0 | 单文件｜≤30 行｜不动接口/库表/路由 |
| L1 | 单端内｜≤4 文件｜不动库表与对外接口 |
| L2 | 命中任一：跨 ≥2 端｜改库表/接口｜新页面或路由｜≥5 文件｜架构选型 |

用户明说「小改 / 别动别的」→ 强制 L0/L1；明说「做功能 / 走全流程」→ 强制 L2。判据不符先驳回，不擅自升档。

## 3 决定本轮走哪条

- L0：直接改 → 编译或单测 → 一句话结果
- L1：定位 → 改 → 测试 → 简短变更说明
- L2 且要写代码：**先 `/ai-plan`**，文档没落不许动手
- 查 bug：走 `diagnose`（复现 → 3-5 个可证伪假设 → 一次改一个变量）
- 界面需求：先读 `.trae/skills/ui-ux-benchmark/SKILL.md`，对标 3 家真实页面再实现

## 4 自举异常先报，不硬撑

`DEGRADED hook` / `LEDGER BROKEN` / `MEMORY MISSING` 任一出现，先把事实和原因告诉用户，再问怎么处理。

## 禁止

- 跳过定档直接改代码
- 把 `NEXT` 当装饰，报完不认
- 自举失败还假装状态正常
